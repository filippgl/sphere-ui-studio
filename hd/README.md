# Текстуры интерфейса 4×

Пакет содержит 92 имени атласов интерфейса и 72 языковых варианта растровых шрифтов. Одинаковые исходники объединены: 107 уникальных DDS, около 187 МиБ после gzip. Атласы увеличены специализированным [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN), модели `realesrgan-x4plus` и `realesrgan-x4plus-anime`.

Каждый размер увеличен ровно в четыре раза. Элементы остаются на исходных местах атласа. Для UI альфа-канал отдельно увеличен из оригинала методом Lanczos: нейросеть обрабатывает цвет, сохраняя исходную прозрачность панелей. Для шрифтов обрабатывается маска букв, результат ограничен оригинальными прямоугольниками SFNT. Если уменьшенная маска символа расходится с исходной (IoU ниже 0,95), для этого символа используется Lanczos. Нормализованные UV шрифтов не меняются.

`manifest.json` связывает SHA-256 исходного DDS с размером, HD-файлом и контрольными суммами сжатых и распакованных данных. Файлы имеют имена по SHA-256 распакованного DDS. Формат DDS: A8R8G8B8, без mipmaps. Сжатие gzip относится к доставке: в клиент записывается обычный `.dds`.

При сохранении увеличенного окна редактор устанавливает нужные DDS под новыми именами в `xadd`, пересчитывает исходные координаты текстур и повёрнутые `tcoords`, сохраняя экранную геометрию. Общий атлас `sprites.ui` обновляется той же транзакцией, чтобы кнопки и значки также использовали HD. Созданные увеличенные шрифты получают HD DDS с прежними именами. Оригинальные атласы игры не заменяются. Новые ресурсы и изменения ссылок отражаются в резервной копии и ZIP.

Неизвестные или изменённые исходные DDS остаются как есть с сообщением о недоступной HD-версии. Игровые файлы не отправляются на сайт для распознавания: контрольные суммы вычисляются локально.

## Пересборка

Для работы редактора пересборка и GPU не нужны. Для подготовки другого пакета нужны оригинальная копия клиента, Python с Pillow, NumPy и SciPy, а также официальный `realesrgan-ncnn-vulkan` с моделями из [релиза](https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.5.0). Сам апскейлер и его модели в репозиторий не включены.

```powershell
node tools/prepare-hd.mjs <папка-клиента> .run/hd-work
python -m pip install pillow numpy scipy
python tools/build-hd.py --jobs .run/hd-work/jobs.json --work .run/hd-work --tool <путь-к-realesrgan-ncnn-vulkan.exe> --output hd --workers 2
```

Видеокарта выбирается параметром `--gpu` (по умолчанию 0). Число параллельных задач задаётся через `--workers`. Промежуточные файлы и пути к клиенту остаются в игнорируемом каталоге `.run`. При изменении исходников используйте новый рабочий каталог: завершённые промежуточные результаты используются повторно.
