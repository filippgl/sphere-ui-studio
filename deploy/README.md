# Размещение статической версии

1. Выполните `npm run build` из нужного Git-коммита.
2. Скопируйте содержимое `dist/` в новый каталог релиза, например `/var/www/sphere-ui/releases/<commit>/sphere/ui/`.
3. Направьте символьную ссылку `/var/www/sphere-ui/current` на каталог релиза `<commit>`. Предыдущий релиз сохраните для отката.
4. Подключите `nginx-sphere-ui.conf` внутри существующего HTTPS-блока сервера. Перед изменением сохраните его конфигурацию.
5. Проверьте конфигурацию через `nginx -t`, затем выполните `systemctl reload nginx`.
6. Проверьте `/sphere/ui/`, тип `text/javascript` для `.mjs` и `/sphere/ui/version.json`. SHA-256 файлов из манифеста должен совпадать с размещёнными файлами.

На сервер выкладываются только файлы из `dist/`. Запускать `server.mjs` на публичном интерфейсе или публиковать его локальные API не требуется.

Для отката верните ссылку `current` на предыдущий каталог релиза. Изменение версии сайта не затрагивает папки клиентов: они находятся на компьютерах пользователей.
